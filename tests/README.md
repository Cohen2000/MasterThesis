# Test suite

The active tests cover the current experiment implementation and its reusable
data, sampling, generation, request, execution and evaluation components.

Current experiment regression tests are under `tests/frozen_main/`.
Data and parsing tests are under `tests/data/`.

Historical experiment-specific tests and diagnostics are preserved under
`archive/` and are not part of the active test suite.

The current experiment protocol is documented in
`docs/PROTOCOL_SRW_20260920.md`.
