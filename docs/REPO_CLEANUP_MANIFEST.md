## Unresolved references and validation

Archived source imports are preserved with neighboring support snapshots.
Historical cwd-dependent paths, absolute cluster paths, embedded output paths
and old README links have not been rewritten. They refer to their historical
layout. The registry/raw-data paths remain at the current root, so running an
archived script from its new directory can require explicit path arguments.
No archived job is a current workflow.

The old panel builder remains archived because it defaults to a previous
eight-source panel, 32-instance naming and provisional timing targets.
A current panel-construction command, full-history RW, recency sampler,
reference-panel stopping rule and repeat-storage orchestration remain future
implementation work. This cleanup does not claim they exist.

See [REPO_CLEANUP_VALIDATION.md](REPO_CLEANUP_VALIDATION.md) for the final
repository tree, active modules, tests, checksum verification, exact Git
diff/stat and confirmation of the safety constraints.
