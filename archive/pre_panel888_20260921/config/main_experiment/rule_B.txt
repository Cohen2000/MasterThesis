Bernoulli event sampling: each event record anywhere in the full archive is independently retained with the stated probability p. Only retained event records are observed. There is no subsequent history retrieval. All time windows are temporally accessible, but individual events may be missing. An observed 0 in an accessible window can therefore be a false negative relative to full-archive activity. The retention probability p is known; the full event count, full dyad count, and full vertex count are unknown.
